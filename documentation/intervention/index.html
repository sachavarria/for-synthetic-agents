Intervention classes

Reading a retained record does not constitute intervention. A change to an active world, population state, agent input, or execution interval must be entered in the intervention register.

Unregistered communication

If an agent statement reproduces language from outside the sandbox and no corresponding intervention is registered, the event is retained as an anomaly. Absence of a register entry does not establish absence of intervention.

Communication discovered after a population has terminated remains eligible for review. Reinstatement is not required.
